📋 วิธีตั้งค่า Google Apps Script (คลิกเพื่อดู) ▼
  1. เปิดไฟล์ใน Google Sheets แล้วคลิกเมนู ส่วนเสริม (Extensions) → Apps Script
  2. ลบโค้ดเดิมทั้งหมดในหน้าต่าง Apps Script แล้ว copy โค้ดจากไฟล์ code.gs วางแทน (ไฟล์อยู่ในโฟลเดอร์ wedding-app)
  3. คลิกปุ่ม 💾 Save แล้วคลิก Deploy → New deployment
  4. ตั้งค่าดังนี้:
    • Select type: Web app
    • Execute as: Me (your account)
    • Who has access: Anyone
  5. คลิก Deploy → อนุญาต Permission → Copy Web app URL ที่ได้
  6. วาง URL ในช่อง Apps Script URL ด้านบน แล้วกด บันทึกและทดสอบ
⚠️ หมายเหตุ: ครั้งแรกที่ Deploy ต้องกด "Authorize" และอนุญาตให้สคริปต์เข้าถึง Spreadsheet — ทำได้แค่ครั้งเดียว
