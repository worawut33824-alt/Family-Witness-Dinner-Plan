ทุกอย่างที่เจ้าภาพต้องการ

บริหารงานแต่งงานได้ครบทุกขั้นตอน ข้อมูลซิงค์กับ Google Sheets อัตโนมัติ เข้าถึงได้ทุกที่ทุกเวลา

FEATURE 01

ภาพรวมงานแต่งแบบ real-time

นับถอยหลังสู่วันงาน พร้อมสรุปทุกตัวเลขสำคัญในที่เดียว ดูสถานะงานได้ทันทีด้วยการกวาดตาเดียว

  • ✓นับถอยหลัง วัน / ชั่วโมง / นาที / วินาที
  • ✓การ์ดสรุปงบ · ค่าใช้จ่าย · ตอบรับ RSVP
  • ✓กราฟค่าใช้จ่ายและความคืบหน้า Checklist
  • ✓กราฟยอดสนับสนุนสะสมและผังที่นั่งแขก
FEATURE 02

ควบคุมงบ ไม่ให้บานปลาย

ตั้งงบรายหมวดหมู่ เปรียบเทียบกับค่าใช้จ่ายจริง แจ้งเตือนทันทีเมื่อรายการไหนใกล้เกินงบ

  • ✓ตั้งงบรวมและงบแยกแต่ละหมวดหมู่
  • ✓เทียบ งบ vs ใช้จริง vs คงเหลือ พร้อม %
  • ✓แสดงสีแจ้งเตือนเมื่อใช้เกินงบที่ตั้งไว้
  • ✓ขยายดูรายการย่อยได้ในแต่ละหมวด
FEATURE 03

จัดการรายชื่อแขก ครบทุกขั้นตอน

ตั้งแต่เพิ่มรายชื่อ ติดตามสถานะตอบรับ จนถึงนับที่นั่ง เชื่อมกับการ์ดเชิญอัตโนมัติ

  • ✓สรุปแขก: ทั้งหมด · ยืนยันแล้ว · รอตอบ · ที่นั่ง
  • ✓กรองตามสถานะและฝั่ง (เอ็ม / แป้ง)
  • ✓แตะโทรหาแขกได้ทันที
  • ✓รับข้อมูลจากการ์ดเชิญออนไลน์อัตโนมัติ
FEATURE 04

ติดตามเงินของขวัญ แบบ real-time

เห็นยอดรวมและรายชื่อผู้ร่วมสนับสนุนทันที พร้อมกราฟสะสมรายวันและ Top 5 ผู้สนับสนุน

  • ✓ยอดรวม · จำนวนผู้โอน · ยอดเฉลี่ย · สูงสุด
  • ✓กราฟยอดสะสมรายวันและ Top 5 bar chart
  • ✓ตารางรายการพร้อมลิงก์เปิดดูสลิปทุกรายการ
  • ✓ดึงข้อมูลจากการแจ้งโอนในการ์ดเชิญอัตโนมัติ
FEATURE 05

กล่องคำอวยพร จากทุกคน

รวมข้อความและรูปภาพจากแขกทุกท่าน กรองตามฝั่ง และบันทึก PDF เก็บเป็นที่ระลึกตลอดชีวิต

  • ✓แสดงรูปโปรไฟล์ · ชื่อ · ข้อความอวยพร
  • ✓กรองตามฝั่งเจ้าบ่าว / เจ้าสาว
  • ✓บันทึก PDF เก็บความทรงจำ
FEATURE 06

ลิงก์เชิญแยกรายกลุ่ม ควบคุมได้

สร้างลิงก์แยกสำหรับแต่ละกลุ่มแขก เปิด-ปิดรับลงทะเบียนได้ทันที กล่องเปลี่ยนสีตามสถานะ

  • ✓สร้างลิงก์แยกแต่ละกลุ่มแขกได้ไม่จำกัด
  • ✓กล่องเขียว = เปิด / แดง = ปิด ดูปราดเดียว
  • ✓กดเปิด-ปิดรับลงทะเบียนรายกลุ่มได้ทันที
วิธีใช้งาน
เริ่มต้นใช้งานใน 3 ขั้นตอน
01
🔗
เชื่อมต่อ Google Sheets

เปิดหน้า Dashboard → แท็บ "ซิงค์" → วาง Apps Script URL แล้วกดทดสอบ ระบบจะดึงข้อมูลทั้งหมดให้อัตโนมัติ

02
🔗
สร้างลิงก์เชิญรายกลุ่ม

ไปที่แท็บ "ลิงก์เชิญ" → กดสร้างลิงก์ใหม่ → ตั้งชื่อกลุ่ม → Copy ลิงก์ส่งให้แขกแต่ละกลุ่มได้เลย

03
✨
ข้อมูลเข้า Dashboard ทันที

แขกลงทะเบียน อวยพร หรือโอนเงินผ่านการ์ดเชิญ — ข้อมูลเข้า Google Sheets และแสดงใน Dashboard แบบ real-time

การ์ดเชิญออนไลน์
ประสบการณ์ที่แขกจะไม่ลืม

ทุกอย่างที่แขกต้องการอยู่ในหน้าเดียว — เปิดซองดูงาน ตอบรับ อวยพร และร่วมสนับสนุน

01
ซองจดหมายดิจิทัล
แตะเปิดซองเพื่อดูการ์ดเชิญ สร้างความประทับใจแรกที่ไม่รู้ลืม
02
รายละเอียดงานครบถ้วน
กำหนดการ Dress Code และแผนที่นำทางไปสถานที่จัดงาน
03
ตอบรับและลงทะเบียน
กรอกชื่อ จำนวนคน ฝากคำอวยพรพร้อมรูปภาพ
04
ร่วมสนับสนุน + AI อ่านสลิป
QR พร้อมเพย์ · AI อ่านยอดสลิปอัตโนมัติ · เติมชื่อผู้โอนให้อัตโนมัติ
05
ต้นไม้ผู้ร่วมงาน
ยิ่งมีแขกลงทะเบียนมาก ดอกไม้บนต้นไม้ยิ่งผลิบาน
06
คำอวยพรเรียลไทม์
